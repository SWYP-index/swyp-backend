# Index 용어 사전
| **한국어** | **영어**    | **설명**                                             |
|---------|-----------|----------------------------------------------------|
| 사용자     | User      | 인덱스 서비스를 사용하는 이용자, 로컬과 소셜 로그인 중복 가입이 가능하다 |
| 책       | Book      | 알라딘 API를 통해 조회하며 한 번 조회한 책은 DB에 저장된다                   |
| 기록      | Record    | 페이지 단위, 책 단위로 느낀 감정과 한줄 평을 기록 할 수 있다   |
| 감정      | Emotion   | 기록에 들어가는 감정, 20가지로 구성 되며 1 - 10 점으로 구성된다        |
| 책상      | Desk | 사용자가 현재 읽고 있는 책 목록과 그에 맞는 추천 책들을 보여준다                               |
| 책장      | Bookshelf | 사용자가 읽은 책을 목록으로 보여준다                               |
| 달력      | Calendar  | 한 달 단위로 어떤 책을 읽었고 감정 기록을 남겼는지 보여준다             |


## 감정 분류
| **대분류** | **설명**                   |
|---------|--------------------------|
| 긍정      | 감동, 설렘, 희망, 공감, 위로       |
| 부정      | 슬픔, 분노, 혼란, 불안, 답답함      |
| 중립      | 충격적인, 차분함, 공허한, 아쉬움, 평온한 |
| 사고기반    | 깨달음, 통찰, 의문, 영감, 반성      |
